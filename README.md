## Selected engineering work

### Openship — Deployment Platform
*TypeScript · Hono · PostgreSQL · Docker*

Worked across the control plane and deployment lifecycle, including cross-process coordination, durable execution receipts, interrupted-build recovery, rollback, and release verification.

[Explore Openship](https://github.com/oblien/openship)

### Mindwire — Agent Runtime & SDK
*Go · TypeScript · Docker · SSH*

Built agent execution and session infrastructure, including persistent turn receipts, retry deduplication, restart reconciliation, and reusable SDK integrations.

[Explore Mindwire](https://github.com/oblien/mindwire)

### LLMProxy — Self-Hosted LLM Gateway
*C# · .NET 10 · PostgreSQL · Redis*

An OpenAI-compatible gateway supporting multiple providers, shared rate limits, transactional usage reservations, idempotent accounting, and failure-aware streaming.

[Source code](https://github.com/Mo7ammedd/LLMProxy) · [Releases](https://github.com/Mo7ammedd/LLMProxy/releases)

### GhostyKey — Encrypted Secret Sharing
*TypeScript · Next.js · PostgreSQL · Web Crypto*

Browser-side AES-GCM encryption with fragment-based decryption keys, transactional consumption, expiration policies, and concurrency-tested one-time access.

[Source code](https://github.com/Mo7ammedd/GhostyKey) · [Live application](https://ghostykey.vercel.app)

### AeroUDP — Experimental Reliable UDP Transport
*Rust · Tokio*

An experimental ordered transport over UDP implementing acknowledgements, retransmission, sliding windows, RTT estimation, and TCP-inspired congestion control.

[Source code](https://github.com/Mo7ammedd/AeroUDP)
